# 🌐 Cisco Packet Tracer Home Lab

A collection of networking labs created in **Cisco Packet Tracer** to build practical knowledge of networking concepts, Cisco IOS configuration, and network troubleshooting.

These labs document my progress as I learn and practice networking fundamentals through hands-on simulations.

## 🧪 Labs

### 🏠 Lab 01: Home LAN

Built a basic wired LAN using a router, switch, PC, laptop, and printer.

**Topics practiced:**

* IPv4 addressing
* DHCP
* Static IP configuration
* Router configuration
* Switch connectivity
* CDP neighbor discovery
* ICMP ping testing
* Basic network troubleshooting

📁 [View Lab 01](./01-home-lan/)

---

### 📡 Lab 02: Wireless LAN with Access Point

Built a wireless LAN by connecting an Access Point to a switch and configuring a laptop with a WPC300N wireless module.

**Topics practiced:**

* Wireless LAN
* Access Points
* Wi-Fi connectivity
* WPC300N wireless module
* DHCP
* Ethernet and wireless communication
* Router and switch connectivity
* Basic network troubleshooting

📁 [View Lab 02](./02-wireless-lan/)
