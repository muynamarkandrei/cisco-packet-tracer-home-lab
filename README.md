A collection of networking labs created in **Cisco Packet Tracer** to build practical knowledge of networking concepts, Cisco IOS configuration, and network troubleshooting.

### 🔢 Lab 03: IP Addressing and Connectivity

Built a small wired LAN using two PCs and a Cisco 2960-24TT switch. The PCs were manually configured with IPv4 addresses and tested for connectivity within the same subnet.

The lab also included changing one PC's IP address to a different subnet to observe how communication fails when there is no router connecting the networks.

**Topics practiced:**

* IPv4 addressing
* Subnet masks
* Manual IP configuration
* Same-subnet communication
* MAC address-based switching
* ARP
* ICMP ping testing
* Understanding the role of a default gateway
* Understanding when a router is required
* Basic network troubleshooting

📁 [View Lab 03](./03-ip-addressing/)
